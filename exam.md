# 🇬🇧 English Version

## Task 1 — Math Class

Create a `Math` class with the following members:

### 1. Public Methods

Implement the following public methods:

- `double Abs(double value);`
- `float Abs(float value);`
- `int Abs(int value);`
- `double Pow(double x, double y);`
- `double Sqrt(int d);`
- `int Max(int val1, int val2);`
- `int Min(int val1, int val2);`

### 2. Constant Fields

Declare the following constant fields inside the `Math` class:

- `const double PI = 3.14;`
- `const double E = 2.71;`

---

## Task 2 — Post Class

In this task, you will create a `Post` class with the following properties:

- `Title` : string
- `Description` : string
- `LikeCount` : int
- `Comments` : `List<string>`
- `IsPublished` : bool

The `Post` class should have the following functionalities:

### 1. `Publish()` Method

- Display the message `"The post is published."`.
- Set `IsPublished` to `true`.

### 2. `Like()` Method

- Increment the `LikeCount` property by 1.

### 3. `Comment(string message)` Method

- Add the comment `message` to the `Comments` list.

### 4. `Program.cs`

- Create a list of type `Post`.
- Create 5 `Post` objects and add them to the `posts` list.
- Use a `foreach` loop to print the information of all posts, following this format:

```text
"{Title} – {Description} – number of Likes: {LikeCount}"
```

### GitHub Requirements

After implementing and testing all methods:

- Create a public repository on GitHub.
- Name your project using the following format: `MyExam`.
